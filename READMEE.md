# PimSync - Product Information Management System

Centralized PIM dashboard to sync products across Shopify, Amazon, Etsy and prevent overselling.

## 🚀 Live Demo
https://github.com/apekshashetkar/pimsync

## 📸 Screenshot
Dashboard shows 2 products, 165 units stock, connected channels

## 💡 Problem Solved
Sellers list same product on 3 channels. When stock sells on Shopify, Amazon still shows old stock = overselling & order cancellation. PimSync syncs inventory in real-time.

## ✨ Features
- Central Product Catalog (SKU, Price, Stock, Variants)
- Multi-channel Sync: Shopify, Amazon, Etsy
- Real-time Inventory (Total Stock 165 -> 215 on new product add)
- Add Product Modal with auto-sync
- Clean Dashboard with Tailwind + Next.js

## 🛠️ Tech Stack
- Next.js 14, TypeScript, Tailwind CSS
- Lucide Icons, Zustand for state

## 🏃 How to Run
npm install
npm run dev
Open http://localhost:3000
